Hermes Agent — Private Integration

Hermes Agent is a private, single-user automation tool operated by one individual for their own use. It is not a public service, it is not distributed, and it has no users other than its operator.

This OAuth client exists so that the operator's own software can access two things on their own Google account:

  • a dedicated mailbox on a Google Account created solely for this purpose (reading messages, creating drafts, applying labels and archiving), and
  • Google Calendar — only those calendars the operator has explicitly shared with that dedicated account, at whatever access level the operator granted.

How the data is handled

All processing happens locally on the operator's own computer. No data is transmitted to or stored on any third-party server, and no Google user data is sold, shared, or used for advertising or for training machine-learning models.

Read the full details on the Privacy Policy page.
