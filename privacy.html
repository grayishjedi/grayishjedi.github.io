Privacy Policy — Hermes Agent

Last updated: 27 September 2026

Hermes Agent is a private, single-user software tool. This policy describes what Google data that software accesses on the operator's own Google account, and what happens to it. There are no other users of this application.

1. What Google data is accessed

Via the Google APIs listed below, and only for the account that authorizes this application:

  • Gmail API (gmail.modify) — read messages in the dedicated mailbox created for this purpose, create and modify drafts, apply labels, archive and delete messages, and send mail. Used to triage mail the operator chooses to forward to that mailbox and to prepare reply drafts for the operator's review.
  • Google Calendar API (calendar) — read event data on calendars shared with the dedicated account, and create, modify or delete events on those calendars, limited by the sharing permission the operator granted.

No other Google services, scopes, or accounts are accessed. The operator's primary Google account is not authorized to this application; access to its calendars is possible only because the operator shared individual calendars with the dedicated account, and only at the level granted.

2. How the data is stored and used

  • All data is processed and stored locally on the operator's own computer.
  • No data is transmitted to, stored on, or processed by any third-party server or cloud service, and there is no analytics, advertising, or telemetry.
  • Google user data is not sold, rented, or shared with any third party, and is not used for advertising or to train machine-learning models.
  • OAuth access and refresh tokens are stored locally in a file readable only by the operator's Windows user account. No Google password is ever stored.

3. Data retention and deletion

Locally cached message and calendar data is retained only as long as it is useful to the operator, and can be deleted at any time. Revoking access (see below) prevents any further access and the application can then no longer read or write any Google data.

4. How to revoke access

  • Google Account permissions: myaccount.google.com/permissions — remove the access grant for this application.
  • Calendar: un-share the calendar in Google Calendar settings ("Settings and sharing" — remove the dedicated account from "Share with specific people"), which revokes access immediately.
  • Mail: delete the dedicated Google Account entirely, or change its password, which invalidates the application's access.

5. Google API Services User Data Policy

This application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
