# grayishjedi.github.io

Static pages used as the **homepage and privacy policy** for a private, single-user
OAuth application integration (Hermes Agent), as required by the Google Cloud
OAuth consent screen ("App domain" fields).

- `/` — homepage (`index.html`)
- `/privacy.html` — privacy policy

Both pages are public by necessity: Google validates that the URLs listed on an
OAuth consent screen are live and hosted on a verified domain. They describe
what the application accesses and how that data is handled. Nothing here is a
product or a service offered to anyone; there is one user, the repo owner.
